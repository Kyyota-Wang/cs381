# markhomepage.com

The source of record for https://markhomepage.com — a static site with two sections:
**Research** (papers, as PDFs with a landing page each) and **Teaching** (interactive
modules for CSC 381/576 Data Science at West Chester University).

No framework, no build step, no server code. Everything under `public/` is uploaded
verbatim to Cloudflare and served as-is.

## Where it lives

| | |
|---|---|
| Production | https://markhomepage.com · https://www.markhomepage.com |
| Fallback | https://csc381.pumpkin-ai-v2.workers.dev |
| Cloudflare Worker | `csc381` (assets only, no script) |
| Git | `Kyyota-Wang/cs381`, branch `main` |
| First deploy | Sep 10, 2026 |

The Worker and the repo are still named `csc381` because the site began as a page of
course modules. Renaming either would break the fallback URL and the git remote for no
gain.

## Deploy

wrangler is authorised on this machine by OAuth (`npx wrangler whoami` to check,
`npx wrangler login` if it has lapsed).

```bash
npm install          # first time in a fresh clone only
npx wrangler deploy
git add -A && git commit -m "..." && git push
```

Deploying and pushing are independent. A push publishes nothing; a deploy backs up
nothing. Do both.

The deploy output must list all three addresses. Note the `Current Version ID` — that is
the rollback point for `npx wrangler rollback <id>`.

Verify:

```bash
for u in / /research/ /visualization/ /nope; do curl -s -o /dev/null -w "$u %{http_code}\n" "https://markhomepage.com$u"; done
```

Expect `200 200 200 404`.
